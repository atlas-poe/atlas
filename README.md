# Atlas

Native Path of Exile toolkit for market trading, crafting, and player knowledge.

## Overview

Atlas is a fast, native desktop companion for Path of Exile, written in Rust. It provides tools for understanding the game's economy and improving your gameplay experience.

### Features (Planned)

- **Item Analysis**: Parse and evaluate items from your clipboard
- **Trade Searching**: Search the official trade API efficiently
- **Price Comparison**: Compare item prices across the market
- **Market Insights**: Track currency trends and market data

## Getting Started

### Prerequisites

- Rust toolchain (stable) - [Install Rust](https://www.rust-lang.org/tools/install)

### Building

```bash
cargo build
```

### Testing

```bash
cargo test
```
